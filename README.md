# CricAnalysis

The finished pages of https://cricanalysis.co.in: cricket match statistics and model estimates.
This repository holds only the built pages. They are rebuilt automatically.

- Match data from [Cricsheet](https://cricsheet.org), used under the Open Data Commons Attribution License.
- Fonts: Sofia Sans and Sofia Sans Extra Condensed, SIL Open Font License 1.1 (licence texts in `fonts/`).
- Statistical analysis for information only. It is not betting advice and carries no guarantee.
